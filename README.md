# Laboratorio-4-HPA-III---Julian-Mosquera-IL133

Aplicación de escritorio en C# con interfaz Windows Forms para la gestión completa de productos (CRUD) conectada a una base de datos, incluyendo soporte para almacenamiento de imágenes.

Estructura del Proyecto

El desarrollo se concentra en un único formulario principal que integra toda la lógica de la aplicación:

Interfaz Gráfica y Diseño (Form1.cs)

Conceptos: Windows Forms, controles de entrada (ID, Folio, Nombre, Precio, Cantidad) y panel visualizador de imágenes.

Funcionalidad: Contiene los campos necesarios para capturar la información del producto y el buscador interactivo con su respectivo botón de consulta.

Conexión y Persistencia

Conceptos: Conexión a base de datos relacional mediante App.config.

Funcionalidad: Almacenamiento seguro de registros estructurados junto con el manejo de archivos de imagen dentro de la base de datos.
